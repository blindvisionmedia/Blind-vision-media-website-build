# Blind Vision Drive Assets Found

The current scaffold uses two optimized brand assets:

- Full blind vision logo → `public/assets/bv-logo-full.jpg`
- Outline transparent logo → `public/assets/bv-logo-outline.png`

Additional brand variants exist in the Blind Vision asset library and should only be added when the site actually uses them. This avoids shipping multi-megabyte unused media into the repository/public bundle.

Use the transparent outline logo as the primary mark on dark public pages. Use colour variants as controlled accents only.
