# Skill: Blind Vision Brand & Visual Review

Use when creating or reviewing any public-facing Blind Vision page.

## Objective

Produce a premium dark/cinematic/editorial creative-company experience, not a generic AI/SaaS layout.

## Workflow

1. Inspect the complete page at desktop and representative iPhone widths.
2. Identify generic patterns, hierarchy problems, and brand inconsistencies.
3. Check imagery/video treatment, typography, spacing, and motion.
4. Check primary CTA clarity and conversion path.
5. Check accessibility and mobile usability.
6. Check perceived performance and media loading behavior.
7. Return precise recommendations before broad redesigns.

## Blind Vision anti-patterns

Flag:

- repetitive rounded card grids,
- gratuitous gradients/glass effects,
- generic startup/SaaS composition,
- fake proof/metrics/testimonials,
- stock imagery inconsistent with the brand,
- excessive copy that weakens visual hierarchy,
- mobile layouts that are simply compressed desktop designs.

## Definition of done

The page feels intentionally art-directed, clearly belongs to Blind Vision Media, supports the required customer journey, remains usable on mobile, and has no obvious AI-template visual language.
