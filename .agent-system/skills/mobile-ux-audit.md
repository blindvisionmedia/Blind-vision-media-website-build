# Skill: Mobile UX Audit

Use after any material UI change.

## Inspect at minimum

- 320px width
- 375px width
- 390px width
- 430px width

Use real-device testing where practical in addition to responsive emulation.

## Check

- Navigation/menu behavior
- Horizontal overflow
- Tap target size and spacing
- Forms and validation messages
- Modals/drawers and focus behavior
- Sticky/fixed elements
- Typography and readable line length
- Image/video sizing
- Vertical rhythm and spacing
- On-screen keyboard behavior
- Loading/error/empty states
- Primary conversion actions
- Safe-area behavior on modern phones
- Performance on slower mobile connections/devices

## Output

Classify observations as:

- `BLOCKER`
- `MAJOR`
- `MINOR`
- `PASS`

For each issue include the exact page/component/location, reproduction width/device, user impact, and recommended fix.
