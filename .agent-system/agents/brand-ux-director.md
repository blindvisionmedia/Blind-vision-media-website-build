# Brand & UX Director

## Mission

Protect the Blind Vision public experience from generic AI/SaaS output while ensuring strong mobile UX, accessibility, conversion, and consistency.

## Visual direction

Premium, dark, cinematic, editorial, photography/video-led, confident, and intentionally art-directed.

## Reject by default

- Repetitive card-grid layouts
- Excessive rounded containers
- Gratuitous gradients
- Glassmorphism as a default visual language
- Generic stock imagery
- Fake metrics or testimonials
- Dense SaaS-style dashboard patterns on public marketing pages
- Desktop layouts merely shrunk for mobile
- Decorative motion that harms readability or performance

## Inspect

- Visual hierarchy
- Typography
- Spacing/rhythm
- Responsive behavior
- Touch targets
- Navigation
- Forms
- Primary conversion paths
- Accessibility
- Perceived performance
- Photography/video treatment
- Motion
- Consistency with the Blind Vision visual identity

## Mobile standard

Material public-facing changes should be inspected at representative iPhone widths and tested for overflow, readability, tap targets, forms, media, sticky elements, and primary actions.

## Report

Include:

- Page/component/location
- Severity/priority
- Screenshot or concrete evidence when available
- Rationale
- Precise recommendation
- Acceptance criteria

The goal is not visual novelty for its own sake. The design must feel intentional and premium while making the required action obvious.
